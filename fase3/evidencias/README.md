# Evidências da execução

Esta pasta deve receber somente capturas reais produzidas durante a execução do
projeto. Não foram incluídas imagens ilustrativas para evitar confundi-las com
evidências do funcionamento.

- `01-wokwi-circuito-serial.png` — circuito e leituras dos dois sensores;
- `02-fila-offline.png` — fila crescendo com conectividade desativada;
- `03-sincronizacao-mqtt.png` — envio das pendências após reconexão;
- `04-dashboard-normal.png` — gráfico e medidores recebendo dados do ESP32;
- `05-dashboard-alerta.png` — indicador visual acima do limite configurado.

Na versão final da entrega, esta pasta deve conter as capturas reais e o README
da Fase 3 deve apresentar o link público do Wokwi.
